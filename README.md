# 🐍 PyKNW Studio

โปรแกรมแก้ไขโค้ดภาษา Python (Desktop Application) สร้างด้วย **Electron + Monaco Editor** ที่มาพร้อมตัวแปลภาษา **Python 3.11 แบบ Embedded** ในตัว ทำให้ผู้ใช้งานสามารถดาวน์โหลดโปรแกรมไปติดตั้งแล้วรันโค้ดได้ทันที **โดยไม่จำเป็นต้องติดตั้ง Python ลงในเครื่อง**

---

## ✨ จุดเด่นและฟีเจอร์หลัก

1. **Standalone No-Install Python Runtime**:
   * มี Python 3.11.9 (Embeddable Package) ฝังอยู่ในโฟลเดอร์ `resources/python`
   * สั่งรันโค้ดผ่าน Child Process โดยตรง ไม่พึ่งพา Environment Variables หรือ Python ในเครื่องผู้ใช้
2. **🖥️ รองรับ GUI ด้วย Tkinter ในตัว (Built-in Tkinter & Tcl/Tk)**:
   * มีโมดูล `tkinter` และรันไทม์ `Tcl/Tk 8.6` ฝังมาพร้อมกับตัวโปรแกรมในโฟลเดอร์ `resources/python`
   * สร้างหน้าต่าง GUI, ปุ่มกด, ช่องป้อนข้อมูล, ป๊อปอัปแจ้งเตือนได้ทันทีโดยไม่ต้องติดตั้งอะไรเพิ่ม
3. **⌨️ รองรับคำสั่ง `input()` แบบ Interactive (Console Input Bar)**:
   * มีช่องป้อนข้อมูล (Input Bar) พร้อมปุ่ม [ ส่ง ] ที่ด้านล่างของหน้าต่าง Console
   * เมื่อรันคำสั่ง `input()` โปรแกรมจะแสดงข้อความถามในทันที และเปิดให้พิมพ์ข้อมูลส่งเข้าไปยังรันไทม์ของ Python ได้อย่างราบรื่น
   * รองรับทั้งการกด **Enter** หรือคลิกปุ่ม **ส่ง** รวมถึงการคลิกที่พื้นที่ Console เพื่อโฟกัสช่องกรอกข้อมูลอัตโนมัติ
4. **🚀 ระบบอัปเดตอัตโนมัติจาก GitHub Releases (Auto-Updater)**:
   * ตรวจจับเวอร์ชันใหม่ล่าสุดจากคลัง [nawa-dev/PyKNW](https://github.com/nawa-dev/PyKNW) อัตโนมัติเมื่อเปิดโปรแกรม
   * หากพบเวอร์ชันใหม่ จะแสดงหน้าต่างป๊อปอัปแจ้งเตือนพร้อมรายละเอียดการเปลี่ยนแปลง (Release Notes) และปุ่ม **[ อัปเดตทันที ]**
   * หากผู้ใช้กดปิดหรือกด **[ ภายหลัง ]** จะแสดงปุ่ม **[ อัปเดต ]** พร้อมไฟกะพริบแจ้งเตือนบนแถบ Toolbar ทันที เพื่อให้ผู้ใช้สามารถคลิกอัปเดตเมื่อใดก็ได้
   * ดาวน์โหลดไฟล์ติดตั้ง (.exe) อัตโนมัติพร้อมแถบแสดงความคืบหน้า (%) และเปิดตัวติดตั้งให้อัตโนมัติเมื่อดาวน์โหลดเสร็จ
   * มีคีย์ลัด **Ctrl + Shift + U** สำหรับจำลองและทดสอบการตรวจพบเวอร์ชันใหม่
5. **Modern VS Code Frameless Titlebar & Flat Toolbar Buttons**:
   * รวมขอบหน้าต่างเข้ากับตัวโปรแกรม (ไม่มีขอบขาวแบบเดิม) พร้อมปุ่มควบคุมหน้าต่างในตัว
   * ปุ่มเครื่องมือแบบ **Flat Toolbar Buttons** ไร้กรอบและกลมกลืนกับพื้นหลัง เมื่อนำเมาส์ไปชี้จะมีแถบไฮไลต์นุ่มนวลสไตล์ VS Code แท้ๆ
4. **🇹🇭 Thai Error Diagnostics (ระบบอธิบายข้อผิดพลาดเป็นภาษาไทย)**:
   * แปลงข้อผิดพลาดของ Python (`SyntaxError`, `NameError`, `TypeError`, `IndentationError`, `ZeroDivisionError`, `IndexError`, ฯลฯ) เป็นภาษาไทยที่เข้าใจง่าย
   * บอกตำแหน่งบรรทัด และไฮไลต์บรรทัดที่เกิด Error เป็นสีแดงใน Editor ทันที
5. **Interactive Visual Line Highlight (Step Execution)**:
   * ระบบไฮไลต์สีเหลืองและเลื่อนตาม (Auto-scroll) บรรทัดที่ Python กำลังรันอยู่แบบเรียลไทม์
   * มีปุ่มปรับความเร็วในการหน่วงเวลา (Step Delay) ช่วยให้ผู้เรียนมองตามทันทีละสเต็ป
6. **Multi-Tab Code Editor (ระบบแท็บแยกอิสระ)**:
   * เปิดและแก้ไขหลายไฟล์พร้อมกันในแท็บแยกอิสระ พร้อมระบบบันทึกสถานะและปุ่มปิดแท็บ
   * แถบแท็บโค้ดแยกออกจากพาเนล Console อย่างชัดเจน
7. **Dockable Console Layout (สลับตำแหน่ง Console ได้)**:
   * มีปุ่มสลับการแสดงผล Console ระหว่าง **ด้านล่าง (Dock Bottom)** กับ **ด้านข้าง (Dock Right)** ได้ทันที
   * แถบ Resizer ปรับขนาดความกว้าง/ความสูงตามทิศทางที่เลือก
8. **🛡️ Anti-External Paste & Anti-Cheat Metadata Signature**:
   * **บล็อกการวางจากภายนอก:** อนุญาตให้คัดลอกและวางได้เฉพาะโค้ดที่คัดลอกมาจากภายในตัวโปรแกรมเท่านั้น บล็อกการลากวาง (Drag & Drop) และบล็อก Paste จากเบราว์เซอร์
   * **ระบบตรวจจับการแอบแก้ไขใน Notepad (Container Security):** ไฟล์ `.pyknw` บันทึกในรูปแบบ Container พร้อมลายเซ็นดิจิทัลเข้ารหัส HMAC-SHA256
   * หากนักเรียนนำไฟล์ไปเปิดใน Notepad แล้วแอบวางโค้ด/แก้ไข เมื่อนำกลับมาเปิดใน PyKNW Studio ระบบจะตรวจพบการดัดแปลงทันที:
     - แสดงแถบแจ้งเตือนสีแดงด้านบนโปรแกรม: `🚨 ตรวจพบการแก้ไขไฟล์จากโปรแกรมภายนอก (Notepad)`
     - แสดงเครื่องหมายเตือน `⚠️` บนแท็บไฟล์
     - **บล็อกปุ่ม [ รัน ] ทันที** ไม่อนุญาตให้ประมวลผลโค้ดที่ไม่ได้เขียนด้วยตนเองในโปรแกรม
     - ไม่อนุญาตให้บันทึกทับเพื่อฟอกขาวลายเซ็น นักเรียนต้องเปิดแท็บใหม่และฝึกพิมพ์โค้ดด้วยตนเองเท่านั้น
6. **Vector Icons UI**:
   * ดีไซน์ระดับ Modern Dark IDE ใช้ไอคอน Vector SVG ทั้งหมด (ไม่มี Emoji)

## 📁 โครงสร้างโปรเจกต์

```text
python_editor/
├── resources/
│   └── python/                # Python 3.11 Embeddable (รันได้ทันทีโดยไม่ต้องลง Python)
├── src/
│   ├── main/
│   │   └── index.js           # Electron Main Process (IPC, File Dialog, Python Process Runner)
│   ├── preload/
│   │   └── preload.js         # Context Bridge & API รักษาความปลอดภัย
│   └── renderer/
│       ├── index.html         # โครงสร้างหน้าต่างโปรแกรม
│       ├── styles.css         # UI Theme (VS Code Dark Modern)
│       └── app.js             # Monaco Editor Config, Anti-Paste Shield, Terminal Output
├── demo.pyknw                 # ตัวอย่างไฟล์ทดสอบ .pyknw
└── package.json               # การตั้งค่า dependencies และ build configuration
```

## ⌨️ คีย์ลัดที่รองรับ (Hotkeys)

| คีย์ลัด | ฟังก์ชันการทำงาน |
|---|---|
| `F5` หรือ `Ctrl + Enter` | สั่งรันโค้ด Python ในแท็บปัจจุบัน |
| `Ctrl + S` | บันทึกไฟล์ (หากกดปุ่ม **รัน** จะบังคับบันทึกทับอัตโนมัติก่อนเสมอ) |
| `Ctrl + Shift + S` | บันทึกไฟล์เป็น (Save As) |
| `Ctrl + O` | เปิดไฟล์ (.pyknw / .py) |
| `Ctrl + N` | สร้างแท็บไฟล์ใหม่ |
| `Ctrl + W` | ปิดแท็บปัจจุบัน |
| `Ctrl + =` หรือ `Ctrl + +` | ซูมขยายตัวอักษรเฉพาะในหน้าโค้ด |
| `Ctrl + -` | ซูมย่อตัวอักษรเฉพาะในหน้าโค้ด |
| `Ctrl + 0` | รีเซ็ตขนาดตัวอักษรกลับเป็น 100% |
| `Ctrl + ล้อเมาส์ (ใน Editor)` | ซูมเข้า/ออกเฉพาะพื้นที่หน้าโค้ด |
| `Ctrl + ล้อเมาส์ (ใน Console)` | ซูมเข้า/ออกเฉพาะพื้นที่ผลลัพธ์ Console |
| `ปุ่ม + / - ใน Console` | ปรับขยาย/ย่อตัวอักษรเฉพาะใน Console |

## 🚀 วิธีเปิดใช้งานในระหว่างการพัฒนา (Development Mode)

เปิด Terminal ที่โฟลเดอร์โปรเจกต์ แล้วรันคำสั่ง:

```bash
npm start
```

## 📦 การสร้างตัวติดตั้งโปรแกรม (Build Windows Installer .exe)

หากต้องการแพ็กโปรแกรมเป็นตัวติดตั้ง (`.exe`) เพื่อนำไปแจกจ่ายให้ผู้อื่น:

1. ติดตั้ง `electron-builder` (หากยังไม่มี):
   ```bash
   npm install electron-builder --save-dev
   ```

2. สร้างไฟล์ติดตั้ง:
   ```bash
   npm run dist
   ```

3. ไฟล์ติดตั้ง (`.exe`) จะถูกสร้างขึ้นในโฟลเดอร์ `dist/` 
   * เมื่อผู้ใช้นำไปติดตั้ง ระบบจะตั้งค่า File Association ให้ไฟล์นามสกุล `.pyknw` เปิดด้วยโปรแกรมนี้โดยอัตโนมัติ
